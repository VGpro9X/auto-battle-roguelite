# V0.20 — Concept Generation Briefs

Status: **B0 READY FOR GENERATION**

These briefs are the source of truth for the first V0.20 generated concept masters. They describe original project art; references from the internet are not production inputs.

## A. Fighter Master — Ash Wanderer

### Purpose
Create the single canonical character master from which all 13 gameplay animation states will be derived.

### Composition
Full-body isolated character, neutral three-quarter side-facing gameplay orientation, entire silhouette visible including feet, generous transparent-safe margin, no environment, no typography.

### Character
Original adult human martial cultivator/wanderer. Medium athletic build. Grounded, agile, capable of melee/ranged/magic without looking locked to one class.

Costume language:
- charcoal/blue-black layered travel combat clothing
- short asymmetric mantle rather than long cape
- split lower coat panels for readable motion
- restrained aged-brass fasteners/talisman hardware
- practical boots and forearm wraps/guards
- one asymmetric shoulder/waist landmark for facing readability
- hands/forearms unobstructed enough for spell/projectile anchors
- subtle muted cyan spirit focus accent, not a permanent full-body glow
- no giant permanent weapon; a compact neutral focus/short weapon may be holstered or minimally present

Face/hair:
- readable stylized adult face, not photoreal portrait detail
- dark hair with a practical tied/controlled silhouette
- calm, dangerous, disciplined expression

Rendering:
- premium painterly 2D game character art
- crisp silhouette and controlled internal detail
- material separation visible at small scale
- dark fantasy + cultivation + martial magic
- restrained values so future VFX can become the brightest elements
- original design, no recognizable franchise costume or logo

Avoid:
long decorative cape, huge shoulder armor, wings, modern clothing, sci-fi armor, excessive jewelry, text, watermark, floating UI, environment, malformed hands, duplicate weapons/limbs.

### Acceptance views
The master is accepted only if it remains readable when reduced to approximate gameplay height and if left/right facing can be mirrored without costume ambiguity becoming visually broken.

## B. Ashen Sanctum V3 — Environment Master

### Purpose
Create one cohesive key-art master that establishes all six production environment layers. The layers will be derived/generated from this single visual identity.

### Composition
Wide 16:9-ish side-view combat arena composition corresponding to logical 1000×560 space. Empty arena: no fighters, enemies, UI or text. Camera near the existing side-on Duel presentation.

### Scene
An ancient ruined cultivation sanctuary built on dark volcanic/ash-covered stone. The arena is sacred but damaged, with monumental architecture and supernatural history rather than generic medieval castle imagery.

Visual elements:
- distant dark mountain silhouettes
- broken sanctuary towers/gates and cultivation architecture
- restrained moon/sky illumination through ash clouds
- old stone arena floor with subtle worn geometric/rune traces
- aged metal/stone details
- sparse muted cyan spirit remnants and ember warmth as secondary accents
- atmospheric ash/fog creating depth
- broken pillars/rocks framing outer foreground edges

Combat readability:
- center floor remains comparatively quiet and medium-dark
- no high-contrast object directly behind normal fighter positions
- brightest persistent environment lights remain below combat VFX brightness
- foreground does not block central combat zone

Layer intent:
1. sky — moon/cloud/ash
2. far — mountains/monumental distant ruins
3. mid — sanctuary architecture
4. ambient — fog/ash/embers
5. floor — combat plane
6. foreground — framing ruins/rocks

Rendering:
- premium painterly 2D game environment
- strong depth separation suitable for 2.5D parallax
- coherent with Ash Wanderer materials/palette
- dark fantasy cultivation identity
- original architecture, no franchise landmarks

Avoid:
characters, readable text, logos, modern buildings, photoreal photography, overly bright floor, excessive micro-detail in combat center, foreground covering center, baked skill effects.

### Acceptance gate
Key art must be separable into six logical layers without obvious perspective contradictions and must remain readable in compact mobile framing.

## C. Generation order
1. Generate Ash Wanderer master.
2. Evaluate silhouette/style/material consistency.
3. Generate Ashen Sanctum master using the locked Art Bible, not by copying fighter pixels.
4. Evaluate combined fighter-over-arena readability.
5. Only then begin production derivatives/animation/environment layers.

No bulk skill icon or VFX generation begins before these two masters establish the visual identity.
